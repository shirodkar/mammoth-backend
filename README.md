# Mammoth Backend API

A backend REST API that serves fascinating facts about woolly mammoths, backed by JPA and PostgreSQL.

[![Contribute](https://img.shields.io/badge/Dev%20Spaces-Contribute-blue?logo=redhat&logoColor=white)](https://devspaces.apps.cluster-zc4gd.dyn.redhatworkshops.io/#https://github.com/shirodkar/mammoth-backend/tree/refactor)

## API

```
GET /backend/api/mammoths          — All mammoth facts
GET /backend/api/mammoths/{id}     — Single fact by ID
GET /backend/api/mammoths/random   — Random fact
```
